# Fuentes

Subconjunto latino (alcanza para español e inglés) de tres fuentes de Google Fonts, con licencia [SIL Open Font License 1.1](https://openfontlicense.org): Bricolage Grotesque (variable, 600–700), Atkinson Hyperlegible (400 y 700) y Silkscreen (400).

Van en el repo para que el front compile sin internet (el paquete de Nix compila sin red).
